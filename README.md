# 镜隙 Jingxi

> AI 角色扮演聊天模拟器 —— 一款完全本地化的 Android AI 伴侣应用，让 AI 角色拥有记忆、情感和社交生活。

[![License](https://img.shields.io/badge/license-MIT-green)](./LICENSE)
[![Android](https://img.shields.io/badge/Android-7.0%2B-blue)](https://developer.android.com)
[![Language](https://img.shields.io/badge/language-Java-orange)](https://www.java.com)

---

## ✨ 是什么

**镜隙**不是普通的 AI 聊天软件。

在这里，每个 AI 角色都像一个真正活着的人——他们有自己的性格、记忆、日程、人际关系，甚至有朋友圈。他们会记住你说过的话，会在合适的时机主动找你聊天，会给你打电话，会因为你的一句话而开心或难过。

你不再是一个对着聊天框打字的人，而是进入了一个以你为中心的、有着完整社交生态的虚拟世界。

> 项目完全本地化运行，不收集任何隐私数据，不上传任何信息。你需要的 AI 模型和 API Key 由你自己配置。

## 🎯 核心功能

| 功能 | 说明 |
|------|------|
| 💬 **AI 聊天** | 支持文字、语音消息、真实图片、AI 生成图片、表情包；消息可引用、编辑、撤回、删除 |
| 📞 **AI 语音通话** | 实时双向语音对话，TTS（MiniMax）+ STT（sherpa-onnx 本地离线 / OpenAI Whisper），通话后自动生成摘要 |
| 📱 **仿智能手机桌面** | 锁屏桌面，实时时钟、天气小部件、自定义照片卡片和签名 |
| 👥 **多角色 + 多人设** | 创建多个不同性格的 AI 角色，你也可以创建多个"自己"的人设用于不同场景 |
| 🧠 **深度记忆系统** | 双层结构化记忆：**情景记忆**（用日记回顾关键互动）、**用户画像**（AI 自主发现关于你的结构化知识）。AI 会在后台自动从对话中学习 |
| 🌐 **关系网络** | 可视化有向图展示角色之间、角色与用户之间的关系，含亲密度评分和互动概率 |
| 📖 **世界书 Worldbook** | 构建 AI 世界的背景设定（前置/中置/后置条目），关键词触发，塑造角色所处的世界 |
| 📅 **日程系统** | 为角色设定每日日程，AI 知道自己"现在在做什么"，互动更真实 |
| 🔔 **主动消息** | AI 角色可以根据日程和时间段，自主决定给你发消息或打电话（深夜自动免打扰） |
| 🎭 **朋友圈** | 类似微信朋友圈的社交动态流，AI 角色可以自动发帖、点赞、评论、互相@互动 |
| 🌤️ **天气提醒便签** | 每日定时结合实时天气数据，生成由角色个性驱动的天气关怀消息 |
| 🗣️ **本地离线语音识别** | 内置 sherpa-onnx 引擎，语音转文字无需联网（也可回退到 OpenAI Whisper） |
| 🎨 **主题个性化** | 深色/浅色模式切换，自定义桌面背景（支持裁剪）、聊天背景 |


## 🛠️ 技术栈

| 技术 | 用途 |
|------|------|
| **Java** | 应用开发语言（100% Java） |
| **Android SDK 34** | 目标 API 级别，最低支持 Android 7.0 (API 24) |
| **Room** | 本地 SQLite 数据库（20 个实体，38 次增量迁移） |
| **Retrofit + Gson** | HTTP 网络请求 |
| **WorkManager** | 后台定时任务（主动消息、朋友圈自动发帖、天气提醒） |
| **Glide** | 异步图片加载与缓存 |
| **sherpa-onnx** | 本地离线语音转文本引擎 |
| **MiniMax TTS** | AI 语音合成（支持情感和语气标签） |
| **OpenAI 兼容 API** | AI 对话生成、图片生成、云端语音识别 |

## 🚀 快速开始

### 前置条件

- 一台 Android 7.0 及以上版本的手机
- 一个 OpenAI 兼容的 API Key（用于 AI 对话）
- MiniMax API Key（用于语音合成，可选）
- 和风天气 API Key（用于天气功能，可选）

> ⚠️ **重要提示：本软件不提供任何 API Key、模型或代理节点。所有 AI 模型和 API 服务需要用户自行准备和配置。**

### 安装

从 [Releases](../../releases) 页面下载最新 APK 文件，直接安装即可。

### 自行编译

```bash
git clone https://github.com/Gaoshufen/jingxiPhone.git
```

用 Android Studio 打开项目，等待 Gradle 同步完成，然后 Build → Build APK。

### 初次配置

1. 首次启动进入引导页，阅读并同意免责声明
2. 进入 **设置 → API 设置**，填入你的 API Endpoint、Key 和模型名称
3. （可选）进入 **语音设置**，配置 TTS 和 STT
4. （可选）进入 **天气设置**，配置天气 API 和每日提醒时间
5. 回到联系人页面，点击 **+** 创建你的第一个 AI 角色
6. 设置角色的名字、性格描述、头像
7. 点击角色 → 开始聊天 🎉
